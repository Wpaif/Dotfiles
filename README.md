# Dotfiles

Tema comum: HackTheBox (verde `#9fef00`, fundo `#141d2b`) no Alacritty, tmux, starship e Helix.

| Arquivo | Destino |
|---|---|
| `.zshrc` | `~/.zshrc` |
| `tmux/tmux.conf` | `~/.tmux.conf` |
| `tmux/tmux-cheatsheet.txt` | `~/.tmux-cheatsheet.txt` |
| `starship/starship.toml` | `~/.config/starship.toml` |
| `alacritty/alacritty.toml` | `~/.config/alacritty/alacritty.toml` |
| `helix/` | `~/.config/helix/` |
| `bin/*` | `~/.local/bin/` (scripts do tmux) |

Requer uma Nerd Font, tmux >= 3.3, starship, zoxide, fzf, eza e wl-clipboard.
